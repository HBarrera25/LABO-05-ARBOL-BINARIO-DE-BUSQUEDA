# LABO 05 – Árbol Binario de Búsqueda (BST) en C++

## 💻 Árbol Binario de Búsqueda (BST) para la gestión de un registro de estudiantes.  

## 📄Funcionalidades
El sistema permite:
1. Agregar estudiantes al árbol
2. Mostrar estudiantes ordenados por carnet
3. Buscar estudiantes por carnet
4. Mostrar estudiantes aprobados
5. Mostrar estudiantes reprobados
6. Calcular el promedio general de notas
7. Mostrar el estudiante con la nota más alta

## 📄 Instrucciones de Ejecución

1. Clona este repositorio en la máquina local:
   ```bash
   git clone https://github.com/HBarrera25/LABO-05-ARBOL-BINARIO-DE-BUSQUEDA.git
2. Busca la carpeta del repositorio clonado y escriba esto en la bash:
   ```bash
   code .

3. Una vez dentro de Visual Studio Code abre una nueva terminal (Ctrl + shift + ñ) y escribe lo siguiente para compilar:
   ```bash
   g++ registro_estudiantes.cpp -o registro_estudiantes
   
4. Ejecutar el programa
   ```bash
   ./registro_estudiantes
